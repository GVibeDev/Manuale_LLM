# Contribuire al Manuale LLM

Grazie per voler contribuire.

Questa repository contiene un'opera editoriale, non una codebase: una modifica formalmente corretta può comunque alterare voce, terminologia o metodo. Per questo le proposte vengono valutate rispetto alla baseline pubblicata.

## Cosa segnalare

Sono particolarmente utili:

- errori fattuali o tecnici;
- riferimenti diventati obsoleti;
- passaggi ambigui o contraddittori;
- refusi e problemi di formattazione;
- esempi che non dimostrano chiaramente il principio dichiarato;
- regressioni tra edizione Markdown e DOCX.

## Come aprire una segnalazione

Quando possibile, indica:

1. capitolo e sezione;
2. frase o passaggio coinvolto;
3. tipo di problema;
4. motivo per cui ritieni necessaria la modifica;
5. fonte verificabile, se la segnalazione è tecnica o fattuale.

Per gli errori usa il template **Errata**. Per proposte più ampie usa **Proposta editoriale/metodologica**.

## Pull request

Le pull request sono benvenute soprattutto per correzioni circoscritte. Mantieni il delta minimo: evita di riscrivere sezioni non coinvolte dalla correzione.

Per modifiche metodologiche o strutturali sostanziali è preferibile aprire prima una issue, così da chiarire scope e criteri di accettazione.

## Principio di versione

Una modifica non entra nella baseline soltanto perché è nuova. Deve migliorare il testo senza introdurre regressioni tecniche, editoriali o terminologiche.
